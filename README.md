# Overflow — Design System Docs

Documentação visual do design system da Overflow Software — tokens, tipografia
e 23 componentes (Button, Alert, Badge, Card, form controls, Navbar, Tabs,
Accordion, Modal, Dropdown, Tooltip, Table, Pagination, Breadcrumb, Progress,
Spinner, List group, Avatar), renderizados ao vivo em React 18.

Fonte dos tokens e das classes: `enxo-labs/os_erp`
(`resources/css/overflow-design-system.css`).

Publicado em GitHub Pages a partir da branch `main`, pasta raiz — ver
[Settings → Pages](../../settings/pages).
